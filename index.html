🎮 UE 团队看板 · 数据仓库

skipperjames / uep-squad-board · 三人小队（我 / 阿泽 / 小满）

这是什么？

这个仓库有两个用途：
① 放 team.js（看板植入组件，通过 GitHub Pages 对外提供）
② 放 board.json（团队看板的数据，三人读写同一份）
注意：数据同步，不是文件同步。HTML 只部署一次，数据放这里。

team.js 植入组件 board.json 团队数据 18 个协作功能

植入到你的工作站（两行）

<div id="niko-team" data-me="a"></div>
<script src="https://skipperjames.github.io/uep-squad-board/team.js"></script>

data-me 填你自己：me=我 · a=阿泽 · b=小满。 样式隔离（Shadow DOM），不会影响你页面一分一毫。

首次设置（管理员做一次）

  1. 把本仓库设为 Public（Settings → General → 最下 Change visibility）。
  2. 开启 GitHub Pages：Settings → Pages → Source 选 main 分支 / (root) → Save。
  3. 生成一个 Fine-grained token，只授权本仓库、Contents 权限 Read and write。
  4. 把 token 发给团队成员，填进各自页面的 data-token。

数据长什么样

board.json 由看板首次同步时自动创建，结构：

{ "DATA": [ 每张资产卡 ], "TRASH": [回收站], "LOG": [操作记录],
  "DISCUSS": { 卡片讨论 }, "COLUMNS": [看板列], "_ts": 时间戳 }

状态自检

打开任意植入了 team.js 的页面，看右上角状态灯：
🟢 已同步 = 通了 · 🟡 本地模式 = 还没填 token · 🔴 失败 = token 权限或仓库名不对
