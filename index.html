🎮 UE 团队看板 · 组件仓

三人小队（我 / 月饼 / 邢锦）· 组件公开，数据私有

这是什么？

本仓库只放组件：team.js（看板植入组件，通过 GitHub Pages 对外提供）。 团队数据不在这个仓 —— 在私有仓 skipperjames/niko-team-data 的 board.json， 靠 token 读写。
数据不分家会出事：公开仓谁都能看，团队数据必须落私有仓。

team.js 植入组件 数据仓 niko-team-data（私有） 18 个协作功能

植入到你的工作站（两行）

<div id="niko-team" data-me="a" data-repo="skipperjames/niko-team-data"></div>
<script src="https://skipperjames.github.io/uep-squad-board/team.js"></script>

data-me 填你自己：me=我 · a=月饼 · b=邢锦。
data-token 填数据仓那把 token（或页面里点 ⚙️ 粘一次，只存在本机，不上云）。
样式隔离（Shadow DOM），不会影响你页面一分一毫。

现状（2026-10-13 已配好）

  1. 本仓 = Public，GitHub Pages 已开启 → skipperjames.github.io/uep-squad-board
  2. 数据仓 skipperjames/niko-team-data = Private
  3. token：Fine-grained，只勾数据仓，Contents = Read and write（三人共用一把）
  4. 成员各自把 token 粘进自己的页面 / NIKO 的 ⚙️ 同步设置

数据长什么样

{ "DATA": [ 每张资产卡 ], "TRASH": [回收站], "LOG": [操作记录],
  "DISCUSS": { 卡片讨论 }, "COLUMNS": [看板列], "_ts": 时间戳 }
